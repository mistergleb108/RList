
# 📋 Интерактивный список
Простой и эффективный инструмент для работы с заметками прямо в браузере. Редактируйте элементы сразу в строке, импортируйте из буфера обмена, экспортируйте данные и другое.

![](https://img.shields.io/badge/%D0%B2%D0%B5%D1%80%D1%81%D0%B8%D1%8F-1.0-blue)
![](https://img.shields.io/badge/%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D0%B8%D1%8F-MIT-green)

Github Page, сайт проекта: https://mistergleb108.github.io/RList/ 

## 📖 Особенности проекта:

Список локально сохраняется в Cookie-файлах браузера

Срок хранения Cookie: 30 дней

Данные сохраняются автоматически каждые 500мс после изменений
